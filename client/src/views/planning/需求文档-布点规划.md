# 布点规划模块 — 功能需求文档

## 一、模块概述

布点规划模块位于配电网规划 Hub 下，提供光伏接入点的全流程规划功能：从光伏电站建模、约束条件配置、空间分析筛选候选点、综合指标评估，到消纳方案编制、造价经济性分析、设备台账管理。

## 二、功能模块

### 2.1 集中式光伏模型集成（/pv-model）

光伏电站的增删改查及设备造价库管理。

- **电站管理**：维护电站基本信息（容量、面板类型、电压等级、坐标、土地类型、电气参数、设备清单）
- **造价库**：维护光伏设备型号及单位成本（组件、逆变器、变压器等）

### 2.2 约束条件配置（/constraint-settings）

配置空间分析的筛选条件，分三大类：

| 类别 | 参数 | 说明 |
|------|------|------|
| 光伏资源禀赋 | 年辐照量、等效利用小时数、倾斜角度、年日照时数、峰值日照时数 | 光照资源下限 |
| 电网网架约束 | 可开放容量、短路容量比、N-1通过率 | 电网接入条件 |
| 土地可用性 | 是否禁止建设、土地类型、土地成本、地形类别 | 土地利用限制 |

配置以 JSON 格式保存至后端，支持恢复默认值。

### 2.3 推荐布点规划（/site-planning → "推荐布点规划" Tab）

#### 2.3.1 空间分析

从 12 个余杭区潜在接入点中，按约束条件筛选候选点：

- **筛选条件**：年辐照量 ≥ 阈值、等效利用小时数 ≥ 阈值、距变电站距离 ≤ 阈值、土地类型 ∈ 允许列表、坡度 ≤ 阈值、非禁止建设区
- **输出**：候选接入点列表（坐标、推荐容量、综合评分、消纳能力、送出距离/成本、土地成本）
- **评分**：基于资源得分、电网得分、土地得分加权计算

#### 2.3.2 接入点空间分布图

将候选点渲染在 CSS 坐标地图上，标注名称和评分，颜色区分（≥85 绿、≥75 黄、<75 红）。

### 2.4 综合指标评估（/site-planning → "综合评估" Tab）

对 12 个潜在接入点进行三个维度的评估：

| 维度 | 评估字段 | 数据性质 |
|------|---------|---------|
| 消纳能力 | 本地最大负荷、本地最小负荷、可调峰能力、可接纳容量 | 模拟调度数据，每次评估变化 |
| 送出通道 | 线路长度（固定）、施工难度（固定）、建设成本（市场波动） | 部分固定，部分变化 |
| 经济性 | 征地成本（市场波动）、租赁费用（市场波动）、环评等级（固定） | 部分固定，部分变化 |

- 点击"综合评估"按钮调用后端接口生成评估数据
- 表格按三维度分组展示所有字段
- 评估时间记录在每条数据中
- "导入数据"按钮预留作为未来从外部系统导入的入口

### 2.5 消纳方案智能编制（/absorption-scheme）

针对候选点生成消纳方案：

- **储能配置**：容量、功率、类型、布局
- **无功补偿**：SVG/SVC 配置
- **线路改造**：导线升级、联络线、变压器升级方案
- **出力/负荷曲线**：24 时段的 PV 出力和负荷数据

### 2.6 造价管理与经济性分析（/cost-analysis）

- **单位造价参数**：设备、建设安装、土地、其他类别的成本参数
- **投资计算**：按装机容量估算总投资及明细（设备、建筑、土地、其他）
- **成本对比**：光伏 vs 传统火电全成本对比
- **ROI 分析**：25 年财务指标（IRR、NPV、回收期、年现金流）

### 2.7 设备台账动态管理（/equipment-ledger）

- **设备 CRUD**：光伏组件、逆变器、变压器等设备条目的增删改查
- **按站点查询**：按光伏电站查看设备清单
- **生命周期记录**：设计选型 → 采购到货 → 安装投运 → 检修维护 → 退役的全生命周期事件追踪

## 三、数据模型

### 3.1 潜在接入点（PotentialSite）

余杭区 12 个模拟接入点，包含：

- **基本信息**：名称、坐标、面积、土地类型、地形、土地成本、是否禁止
- **资源禀赋**：年辐照量、等效利用小时数、年日照时数、峰值日照时数
- **电网接入**：距变电站距离、可开放容量、短路容量
- **建设条件**：坡度、描述

### 3.2 候选接入点（CandidatePoint）

经空间分析筛选生成的推荐点位，包含筛选后的推荐容量、综合评分、各项得分、送出成本等。

### 3.3 综合评估（ComprehensiveEvaluation）

每个接入点的三维度评估数据，包含评估时间戳。

## 四、用户交互流程

```
进入布点规划页面
│
├─ 推荐布点规划 Tab
│  1. 配置约束条件（或使用默认值）
│  2. 点击"执行空间分析"
│  3. 查看候选点列表和空间分布图
│
├─ 综合评估 Tab
│  1. 点击"综合评估"
│  2. 查看所有接入点的消纳能力/送出通道/经济性数据
│
├─ 消纳方案编制
├─ 造价分析
└─ 设备台账管理
```

## 五、技术实现要点

- 前后端通过 `@new-energy/shared` 共享类型定义
- 后端当前使用内存模拟数据，后续可接入数据库
- 评估数据中固定字段（线路长度、施工难度、环评等级）为确定性计算，可变字段（负荷、成本）每次评估合理波动
- 页面遵循极简 UI 风格：白底灰框、无装饰、无说明文字
